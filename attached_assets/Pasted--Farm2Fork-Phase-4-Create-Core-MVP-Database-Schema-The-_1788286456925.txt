8. ROW LEVEL SECURITY
==================================================

Enable RLS on:

profiles
farmers
buyers
crop_listings
orders
order_items

Create secure policies.

GENERAL RULE:

Users can access their own profile.

FARMERS:

- Can read their own farmer profile.
- Can create/update their own farmer profile.
- Can create crop listings belonging to themselves.
- Can view/update/delete their own crop listings.
- Should NOT be able to modify another farmer's listings.

BUYERS:

- Can read their own buyer profile.
- Can create/update their own buyer profile.
- Can view ACTIVE crop listings.
- Can create orders as themselves.
- Can view their own orders.

FARMERS:

- Can view orders associated with themselves.
- Can update order status only for orders associated with themselves.

USERS:

- Must NOT be able to access another user's private profile information unnecessarily.

IMPORTANT:

RLS must be based on auth.uid() and the profile/farmer/buyer relationships.

Do NOT trust a user_id, farmer_id, or buyer_id supplied by the frontend.

Do not create policies that effectively allow unrestricted access such as:

USING (true)

unless there is a clearly justified public-read requirement.

ACTIVE crop listings may be publicly readable only if the policy is deliberately designed for that purpose.
